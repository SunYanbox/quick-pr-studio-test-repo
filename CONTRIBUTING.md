# Contributing to quick-pr-studio-test-repo

Welcome! This is a sandbox repository for testing [Quick PR Studio](https://github.com/SunYanbox/quick-pr-studio). Any well-intentioned Pull Request is welcome.

## What PRs Are Welcome

- Editing existing files
- Adding new files (text, code snippets, documentation)
- Testing the Quick PR Studio extension workflow
- Any other constructive change

## Prohibited Content

Pull Requests containing any of the following will be rejected:

- Pornography, sexually explicit content, or NSFW material
- Content involving minors in inappropriate contexts
- Terrorism or violence-related content
- Political propaganda or sensitive political topics
- LGBT-related controversial or offensive content
- Any other content that harms community atmosphere

## No Format Requirements

There are **no PR format requirements** for this repository. You do not need to follow a specific template, title format, or description style. Just submit your changes.

## File Size Limit

Files larger than **100 KB** are not allowed. Our CI pipeline will reject any commit containing files exceeding this limit.

This limit is in place to prevent the repository from growing too quickly in size when a large number of PRs are merged.

## Critical Files

The following files are protected and can only be modified by the repository owner:

- `LICENSE`
- `README.md` / `README_ZH_CN.md`
- `CONTRIBUTING.md` / `CONTRIBUTING_ZH_CN.md`
- `.github/` directory contents
- `.gitattributes`

If your Pull Request modifies these files, the repository owner will be automatically added as a reviewer.

## Code of Conduct

Be respectful, be constructive. Do not submit harmful, offensive, or disruptive content.
