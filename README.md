# quick-pr-studio-test-repo

A sandbox repository for testing **Quick PR Studio** — a VS Code extension that creates GitHub Pull Requests using a git worktree workflow.

## About This Repository

This repo is intentionally minimal. It contains **no source code** — it exists solely as a practice ground for creating Pull Requests with the [Quick PR Studio](https://github.com/SunYanbox/quick-pr-studio) extension.

**Any well-intentioned Pull Request is welcome here**, as long as it does not contain prohibited content (see [CONTRIBUTING.md](CONTRIBUTING.md)). There are no PR format requirements — just clone, fork, or use the extension to create a PR and see how it works.

## Quick Start

1. Install [Quick PR Studio](https://github.com/SunYanbox/quick-pr-studio) from VS Code Marketplace
2. Fork this repository
3. Make any change (edit a file, add a file, etc.)
4. Use Quick PR Studio to create a Pull Request
5. Watch the worktree workflow in action
