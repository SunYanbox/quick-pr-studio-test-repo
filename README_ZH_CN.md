# quick-pr-studio-test-repo

用于测试 **Quick PR Studio** 的沙箱仓库 — 一款基于 git worktree 工作流在 VS Code 中快速创建 GitHub Pull Request 的扩展。

## 关于本仓库

本仓库内容极简，**不包含任何源码**，专门用作 [Quick PR Studio](https://github.com/SunYanbox/quick-pr-studio) 扩展的 Pull Request 练习场。

**欢迎任何善意的 Pull Request**，只要不包含违禁内容即可（详见 [CONTRIBUTING.md](CONTRIBUTING.md)）。没有 PR 格式要求 — 直接克隆、Fork，或使用扩展创建 PR 体验工作流程。

## 快速开始

1. 从 VS Code Marketplace 安装 [Quick PR Studio](https://github.com/SunYanbox/quick-pr-studio)
2. Fork 本仓库
3. 做任意修改（编辑文件、新增文件等）
4. 使用 Quick PR Studio 创建一个 Pull Request
5. 观察 worktree 工作流的执行过程
